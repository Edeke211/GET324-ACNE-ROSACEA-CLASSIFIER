# GET 324 Mini-Project — Acne vs Rosacea Classifier

Binary image classifier distinguishing Acne from Rosacea, built for the
GET 324 Laboratory Exercise 10 mini-project (Group CV5).

## Model
MobileNetV3Small transfer learning (fine-tuned), trained in TensorFlow/Keras.
Test accuracy: 86.0%.

## Dataset
"Human Skin Diseases (Image)" dataset (Kaggle), Acne and Rosacea classes only.

https://rosacea-acne-classifier-pgenahffiyezqdl66wgm94.streamlit.app/
